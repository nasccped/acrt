`acrt` pretend to be a more ergonomic and easy-to-use testing tool, working similar to already
existing runtimes such as [cargo test](https://rustwiki.org/en/cargo/commands/cargo-test.html) and
[google test](https://google.github.io/googletest/).

This project is still on development. Keep tunned to get update reports!
